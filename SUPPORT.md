# ESPFlight Support

Use the official ESPFlight documentation first, then open an issue in the repository that owns the affected component.

## Start here

- Website: https://espflight.com
- Documentation: https://espflight.com/docs/
- ESPFlight v1.0 build path: https://github.com/espflight/docs/blob/main/BUILD_V1.0.md

## Choose the right repository

### Firmware

Flight control, stabilization, sensors, motor behavior, failsafe logic, telemetry, Protocol 2, build or flashing issues:

https://github.com/espflight/firmware/issues

### Hardware Reference

Schematic, PCB, BOM, fabrication files, assembly, power, connectors, or reference-board questions:

https://github.com/espflight/hardware/issues

Public EasyEDA project:

https://oshwlab.com/eng_karimizadeh/project_xfbshxkb

### ESPFlight Application

Android APK, discovery, connection, telemetry, controls, configuration, UI behavior, or application release issues:

https://github.com/espflight/application/issues

### Documentation

Missing, unclear, incorrect, or outdated documentation:

https://github.com/espflight/docs/issues

## Before reporting a problem

Please include the exact component versions you are using.

The validated ESPFlight v1.0 baseline is:

- Firmware v1.0.0
- Hardware Reference v1.0
- Application v1.0.0
- Protocol 2

Remove passwords, Wi-Fi credentials, private keys, signing material, and other secrets from screenshots, logs, or configuration snippets.

## Security issues

Do not publish sensitive exploit details in a public issue. Follow the ESPFlight Security Policy for confidential reporting guidance.

## Safety

If a problem could produce unexpected motor output, uncontrolled flight, unsafe ARM / DISARM behavior, or unreliable failsafe behavior, stop powered testing and return to propeller-off bench validation where appropriate.
